# bookgenerator-ai-funnel

Animiertes Werbe-Deck / Landingpage für bookgenerator.ai (16 Folien, 16:9).

- `index.html` – komplette Seite (HTML, CSS, JS in einer Datei)
- `logo.png` – Wortbildmarke bookgenerator.ai

Steuerung: Pfeiltasten / Wischen, `A` = Auto-Play, `H` = Aufnahme-Modus (Steuerung aus), `F` = Vollbild.
Deep-Links auf einzelne Folien z. B. `/#loslegen`, `/#ablauf`.

Hosting: statische Seite, kein Build nötig (Vercel: Framework „Other“).
